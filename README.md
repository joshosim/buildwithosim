# BuildWithOsim - Portfolio Website

A modern, responsive portfolio website built with Next.js showcasing the work and services of Osim Uka, a software developer, creative designer, and digital creator.

## About

This portfolio website features:
- **Personal Brand**: Showcasing skills in web development, mobile apps, UI/UX design, and digital products
- **Project Portfolio**: Display of completed projects with detailed descriptions and tech stacks
- **Blog Section**: Insights on personal development, finance, tech, and creative living
- **Digital Shop**: Platform for selling digital products and templates
- **Contact Integration**: Multiple ways to connect including social media and WhatsApp

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **UI Components**: Lucide React icons
- **Forms**: React Hook Form with Yup validation
- **State Management**: TanStack Query (React Query)
- **Notifications**: React Hot Toast
- **Animations**: Framer Motion

## Features

- ✨ Modern glass morphism design
- 📱 Fully responsive layout
- 🎨 Smooth animations and transitions
- 📧 Contact form with validation
- 🛍️ Digital products showcase
- 📝 Blog with categorized posts
- 🔗 Social media integration
- 💬 WhatsApp direct messaging

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
